# Концепция личного кабинета «Своё Вино»

**Вход:** 1 клик через Яндекс ID / VK ID (без ввода почты и кодов).
пока делаем заглушку. просто входим по кнопке-имитации. нигде никакие данные не храним, только в браузере

**Возможности после регистрации:** Сохранение истории сканирований, формирование персонального «Винного погреба» (избранное), написание дегустационных рецензий и заметок.

**Первичная настройка (микро-квиз):** Выбор базовых предпочтений:
- Цвет: красное / белое / розовое
- Сахар: сухое / полусухое / полусладкое / сладкое

**Эволюция и рекомендации:** Предпочтения автоматически корректируются на основе лайков и оценок. Работают умные рекомендации на основе коллаборативной фильтрации: *«Пользователи с вашим вкусом высоко оценили это вино»*.

---

### Визуализация профиля

**Прогресс-бар: «Путь лозы»**  
Растет от активных действий (сканы, лайки, отзывы):
- 0% → почка на веточке
- 25% → цветки
- 50% → зеленая гроздь
- 75% → налитая цветом гроздь
- 100% → полная гроздь с золотым ореолом

**Фруктовая палитра (цвет + сахар)**  
От сухого к сладкому:
- **Красное:** Вишня → Смородина → Клубника → Арбуз
- **Белое:** Лимон → Яблоко → Груша → Ананас
- **Розовое:** Грейпфрут → Кизил → Гранат → Малина

**Региональные символы**  
- Краснодарский край: Кубанский колос
- Крым: Таврическая амфора
- Дагестан: Дагестанская крепость
- Ставрополье: Врата Предгорья
- Ростовская область: Донской предел
- Нишевые регионы: Винный следопыт (компас-штопор)

**Высшая лига: Статусы**  
- 🖼️ **Коллекционер Третьяков** — за 20+ вин в «Избранном»
- 🗺️ **Путешественник Конюхов** — за вина из 3+ разных регионов
- ✒️ **Критик Белинский** — за 3+ развернутых рецензии
